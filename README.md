## 🖥️ О проекте

RavaOS — это операционная система с собственным ядром **RavaKernel**, файловой системой **RavaFS** и графическим интерфейсом **RavaUI**.

### Особенности
- ⚡ Молниеносная скорость загрузки (< 5 сек на SSD)
- 🛡️ Продвинутая безопасность (MAC, изоляция процессов)
- 💻 Собственное микроядро на C и ассемблере
- 🎨 Современный интерфейс (120 FPS)
- 📦 Менеджер пакетов RavaPM
